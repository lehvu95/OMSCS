# Synchronization of Coupled Network Oscillators

| Synchronization is a very important property of both natural and technological systems.  |
| In broad terms, synchronization refers to any phenomenon in which several distinct but  |
| coupled, dynamic elements have a coordinated dynamic activity. For example, all the  |
| devices that are connected to the Internet have synchronized clocks using a distributed  |
| protocol called NTP, Network Time Protocol. Interestingly, this protocol works quite well  |
| despite the fact that, Internet delays are unknown and time varying and the complete  |
| topology of the internet is not known. A classic example of emergent synchronization is  |
| shown in this YouTube video. Five metronomes are placed on a moving bar so that the  |
| motion of its metronome is loosely coupled with the motion of others. The metronomes  |
| start from a random phase and under certain conditions that we will discuss later in this  |
| lesson, they can get completely synchronized after some time as this video shows. Note  |
| that in this case, the communication between the five dynamic elements is only indirect.  |
| The metronomes do not exchange any messages instead, each of them affects to a small  |
| degree, the movement of the underlying board and that board affects the movement of every  |
| metronome. Another example of self organized synchronization in nature is when many  |
| fireflies gather close together as this image shows. Note that its firefly cannot see all  |
| other fireflies such global communication is not necessary in synchronized systems.  |
| Instead, the remarkable effect is that a large number of systems can get synchronized at  |
| least for a period of time, even if each of them can only communicate locally with other  |
| nearby systems. Similar distributed synchronization phenomena also take place with flocks  |
| of birds, and schools of fish, forming fascinating dynamic patterns. In technology,  |
| similar problems emerge when we have a group of robots, autonomous vehicles or drones  |
| that need to coordinate without having a centralized controller. Our brains also rely on  |
| short term synchronization between thousands of neurons, so that different brain regions  |
| can communicate. This type of synchronization, referred to as coherence is shown at this  |
| video. The video shows three views from the lateral and dorsal of the zebrafish brain  |
| using calcium imaging. Whenever a cluster of neurons fires, the corresponding part of the  |
| brain lights up. Note how different brain regions get active at about the same time,  |
| occasionally producing large avalanches of neural activity throughout most of the brain.  |
| Synchronization is not always a desirable state, however, for example, too much  |
| synchronization in the brain can cause seizures. This image shows EEG recordings during  |
| the onset of an epileptic seizure. The scissor starts at about the middle of the blood,  |
| and it shows major waves discharges at the frequency of about three hertz over most of  |
| the patient's cortical surface. |
