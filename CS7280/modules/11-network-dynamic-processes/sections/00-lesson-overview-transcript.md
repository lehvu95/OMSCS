# Introduction to Other Network Dynamic Processes

| Text |
|------|
| In the last two lessons, we focused on spreading phenomena on networks, such as epidemics  |
| or information cascades. In this lesson, we will discuss some more dynamic network  |
| phenomena. Recall that dynamics of networks refers to problems in ways that topology  |
| changes over time, while dynamics on networks refers to time dependent processes that  |
| take place on a static network. We start with the problem of network robustness. What  |
| happens when we remove nodes from a network randomly, and what happens when we target  |
| high degree nodes? Then, we will talk about the problem of distributed circuits on  |
| networks. How do you find the node or some information on a network, when there is no  |
| central directory? The third problem we will discuss is, synchronization on networks. How  |
| is it possible that the large number of nodes, can get synchronized in a self organized  |
| manner, depending on the underlying network. The fourth problem relates to network  |
| control. How can we drive the state of each node in the network, to a desired operating  |
| point? And how can we do that by driving the minimum number of inputs? Finally, we close  |
| this lesson with coevolutionary or adaptive networks. These are networks in which the  |
| topology changes depending on the state of the nodes, but also the state of the nodes  |
| changes as a function of a topology. This feedback loop creates very interesting self  |
| organization phenomena. |
