| The previous lesson focused on epidemics, which is a spreading process on complex  |
| networks. Viruses are not the only things that spread on a network. However, information,  |
| opinions, means, behaviors are examples of other spreading processes or networks,  |
| especially social network. Such spreading processes are driven by human influence  |
| mechanisms. It is part of human nature to form social networks and to use those networks  |
| to disseminate information in all forms. In this lesson, we will focus on the diffusion  |
| of information on networks. We will start with some common empirical findings about the  |
| cascades that these diffusion processes create. We will also review some common  |
| mathematical models. So it says the linear model, but that often used to study side's  |
| processes. Then we will examine an important optimization problem in the context of  |
| network diffusion. If we start a cascade from, say k nodes, which nodes should we select  |
| to maximize the size of the cascade? Another important question we focus on is the  |
| relation between the community structure of a network and the extent of the diffusion  |
| process on that network. Finally, we will present the case study of network diffusion on  |
| brain networks in the context of multi sensory integration |
