# Step 5: ID Verification Onboarding Quiz

> Source: Canvas — CS-7280-O01, OAN (Summer 2026)

## Objective

This ID verification onboarding quiz aims to ensure that you have read [Georgia Tech's Honor Code](https://policylibrary.gatech.edu/student-life/academic-honor-code) and understand its principles. Additionally, the objective of this is to verify the identity of all GT online students. All online students are *required* to complete the ID verification onboarding quiz that uses Honorlock.

## Instructions

You must open the quiz in Google Chrome and follow the instructions to install Honorlock Chrome Extension. You do not need an access code. If it prompts for an access code, it means you did not open the quiz in Google Chrome and/or you did not install the Honorlock Chrome Extension.

If you are having issues with Honorlock after installing the Honorlock Chrome extension, please contact Honorlock.
