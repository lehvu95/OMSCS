## Overview

In-depth study of the process of developing software systems, including: use of software processes in actual product development; techniques to ensure software quality; and maintenance tasks as software evolves. Students experience multiple process types from rigid to agile, and learn modern technologies and development techniques.

## Before Taking This Class

**Suggested Background**

Students should be familiar with Java and basic software engineering concepts. An undergraduate software engineering course or industry experience is expected.

Self-assessment questions:
- Have you taken a software engineering course or worked as a software engineer?
- Are you familiar with requirements, software design, and software testing?
- Are you familiar with Java? (C++ or C# may suffice, but all assignments are Java-based)
- Are you comfortable learning new technologies and software tools?
- Can you work with a team that meets remotely on a regular basis?

**Technical Requirements**

- Browser: Chrome or Firefox (up-to-date); IE 9+ desktop also supported
- Connection: 2+ Mbps recommended (0.768 Mbps minimum)
- OS: Windows XP+, macOS 10.6+, or any recent Linux distro
- Ability to install free software (e.g., Eclipse IDE)
- Google Hangouts for office hours
