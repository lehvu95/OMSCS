## General Course Information

### Description

This is a graduate-level, hands-on course about software engineering. The goal is to study and learn the way software is specified, designed, developed, verified, and maintained. Students complete individual assignments, a group project, and an individual project. By the end of the course, students will understand the role of software processes in the development of software and will have experienced several types of processes, from rigid to agile. Students will also be exposed to a variety of modern technologies and tools and understand their connection to software processes.

### Prerequisites

- Taken a software engineering course before, or have experience working as a software engineer
- Familiar with basic software engineering concepts (requirements, software design, software testing)
- Familiar with Java; knowing C++ or C# may suffice, but all assignments and projects are Java-based
- Comfortable learning new technologies and working with software tools
- Enough flexibility to work with a team that meets remotely on a regular basis

> If you don't satisfy one or more requirements, seriously consider taking the course in a later semester.

## Assignments & Projects

### Release & Due Dates

- Assignments released ~1 week before due date; not posted early
- Most deadlines: **Sunday at 11:59 PM [AOE](https://en.wikipedia.org/wiki/Anywhere_on_Earth)**
- Scope: ~10 hours of work per assignment (3-credit-hour expectations)

### Submission

- All submissions via Georgia Tech GitHub (two repos: individual and team)
- Submit commit ID to Canvas or Gradescope as specified per assignment
- Server timestamp is authoritative — local `git log` timestamps do not count

### Late Submission Policy

- **50% credit** if submitted within 2 days after the deadline
- **0 points** after the late deadline
- No extensions except through the Dean of Students office (contact before deadline)

### Grading Timeline

Grades returned within ~2 weeks of assignment close.

### Grade Challenges

- Must be submitted within **2 weeks** of grade release
- Submit via Ed Discussion → private question → "Grade challenges" category
- Include: GT username (and team number if applicable), specific dispute with reasoning
- Grade challenges may result in a higher, identical, or lower grade

## Class Policies

### Academic Honesty

All students must abide by the [Georgia Tech Academic Honor Code](https://osi.gatech.edu/students/honor-code).

- **Prohibited:** copying code from any current or former student, or public sources
- **Prohibited:** using AI generative tools (ChatGPT, GitHub Copilot) on assignments
- **Allowed:** isolated, project-agnostic snippets with explicit citation comments:
  ```
  /* BEGIN CODE FROM (source URL) */
  … borrowed source code …
  /* END CODE FROM (source URL) */
  ```
- Do not post solutions or assignment content publicly (during or after the course)
- Plagiarism-detection software is used on all submissions

### Communication Policy

- All class-related communication via Ed Discussion (not email)
- Check GT email and Ed Discussion at least once daily
- Keep questions public when possible; use private posts only for personal/grade concerns
- Unofficial student channels discouraged — you assume responsibility for their content
