# CS 6300 — Software Development Process

**Georgia Tech OMSCS | Spring 2026**

This repository is a reference for CS 6300 (Software Development Process), an OMSCS course covering the full software development lifecycle: requirements, design, implementation, testing, and process models.

No submission files, answers, or personal notes are included.
